# Anniversary surprise

A private two-year anniversary website: passcode lock → surprise → three gifts (a letter in a wax-sealed envelope, our day, and 24 reasons).

## Open it
Double-click `open-site.bat` (it starts a small local server so the music can play), or host the folder on any static host.

## Edit
- Text, passcode, dates, reasons and music: the `CONFIG` block at the top of the `<script>` in `index.html`.
- Photos: `images/photo1.jpg` … `images/photo15.jpg`.
- Optional own song: `music/song.mp3` (plays instead of YouTube).
